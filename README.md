# A las Brasas · Existencias

**[Entrar a la app (PWA)](https://aminramirezvilla-hue.github.io/a-las-brasas-existencias/)** · **[Inventario](https://aminramirezvilla-hue.github.io/a-las-brasas-existencias/#/inventario)**

Si ves esta página de texto en lugar de la parrilla oscura, abre el primer enlace y recarga (el README no es la app).

PWA para marcar **Hay / Bajo / Falta** en los 88 insumos reales de la parrilla **A las Brasas** (Calle Eduardo Mendoza SN, Col. Viguri, Chilpancingo, Guerrero).

Los datos viven en el teléfono (no hay cuentas ni nube). Cada dispositivo guarda su propio conteo.

## Instalar en el celular

Cuando ya veas la app (no este texto):

**iPhone / iPad (Safari)**
1. Abre el enlace de la app.
2. Toca **Compartir** (cuadrado con flecha).
3. Toca **Agregar a pantalla de inicio**.

**Android (Chrome)**
1. Abre el enlace de la app.
2. Menú **⋮** → **Instalar aplicación** o **Agregar a la pantalla principal**.
