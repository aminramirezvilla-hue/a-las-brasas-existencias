# A las Brasas · Existencias

PWA para marcar **Hay / Bajo / Falta** en los 88 insumos reales de la parrilla **A las Brasas** (Calle Eduardo Mendoza SN, Col. Viguri, Chilpancingo, Guerrero).

Los datos viven en el teléfono (no hay cuentas ni nube). Cada dispositivo guarda su propio conteo.

## Descargar la PWA

- [ZIP listo para instalar / subir a Pages](https://github.com/aminramirezvilla-hue/a-las-brasas-existencias/releases/latest)
- El ZIP es la carpeta `docs/`: `index.html`, iconos, logo y la app. No hay que compilar.

## Instalar en el celular (después de abrir la URL pública)

**iPhone / iPad (Safari)**

1. Abre el enlace de la app.
2. Toca **Compartir** (cuadrado con flecha).
3. Toca **Agregar a pantalla de inicio**.
4. Confirma. Queda el icono de A las Brasas como una app.

**Android (Chrome)**

1. Abre el enlace de la app.
2. Menú **⋮** → **Instalar aplicación** (o **Agregar a la pantalla principal**).
3. Confirma.

La app funciona en parrilla aunque se corte el internet, después de la primera carga.

## Publicar en GitHub Pages (este repositorio)

El sitio ya está preparado en la carpeta `docs/`. Si Pages no se ve todavía, actívalo así:

1. Entra a este repositorio en GitHub.
2. **Settings** (arriba a la derecha).
3. En el menú izquierdo: **Pages**.
4. **Source:** *Deploy from a branch*.
5. **Branch:** `main`.
6. **Folder:** `/docs`.
7. **Save**.

En uno o dos minutos la app queda en:

`https://aminramirezvilla-hue.github.io/a-las-brasas-existencias/`

El repositorio es **público**: cualquiera con el enlace puede abrirla. Los faltantes de cada quién se quedan en su propio teléfono.

## Publicar en OTRO repositorio (si copias el ZIP)

1. Crea un repositorio **público** en tu cuenta de GitHub.
2. Sube **el contenido** de este ZIP (o de la carpeta `docs/`) a una carpeta llamada `docs` en la rama `main`.
3. Settings → Pages → Deploy from a branch → `main` → `/docs` → Save.

Si el repositorio se llama distinto de `a-las-brasas-existencias`, las rutas de la app no coincidirán. En ese caso usa este mismo repositorio, o pide que se vuelva a generar con el nombre nuevo.
